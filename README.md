# TDK Broadband RDK Ready Tests

This branch represents the proposed RDK Ready test-only structure for the
Broadband test repository.

## Included

- RDK Ready TM-side Python test scripts
- Test XML and configuration files
- Required module XML files
- TDKB_E2E and TDKB_TR181 module metadata
- Test versioning metadata

## Excluded

- DUT component stubs
- TDK agent code
- Native DUT libraries
- Device service and runtime files
- DUT build files
- HAL-specific and non-RDK Ready test modules

This is a reference feature branch for the planned repository separation.
