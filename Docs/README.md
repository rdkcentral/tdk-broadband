# Docs Overview

This folder contains the low level test specification documents, Execution guide, Test setup configuration documents and Traceability documents for broadband validation suites.

## Low Level Test Specifications

- Platform Compliance test specification: `PlatformComplianceValidationSuite_TestSpecification.md`
- Data Model test specification: `DataModelValidationSuite_TestSpecification.md`
- Device Management test specification: `DeviceManagementValidationSuite_TestSpecification.md`
- Connectivity and Platform Services test specification:
  - `ConnectivityAndPlatformServices_TestSpecification_Section1.md`
  - `ConnectivityAndPlatformServices_TestSpecification_Section2.md`
- Performance and Stability test specification: `PerformanceAndStabilityValidationSuite_TestSpecification.md`

## Execution Guide

Document defining the approach for validating that broadband devices meet the
requirements established by the RDK-B specification.

## Test Setup Configuration

Documents detailing the hardware and software setup bring-up (where external test components are involved). 

## Traceability 

Documents to trace the tests to the High Level test specification requirement ID.

## Note

The Connectivity & Platform Services Low Level Spec is too big to render in GitHub. Hence, the spec is available as 2 sections with `Section1` and `Section2` appended to the file names.
